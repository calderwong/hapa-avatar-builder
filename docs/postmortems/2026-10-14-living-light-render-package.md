# Exact saved Journeys become self-contained render input

Prototype checkpoint,2026-10-14. Source: Codex /root chat
01a137cc-de1d-7511-ab65-227c92d5bca0. Goal active; LL-903 not closed.

Objective: make the saved painted album cut reproducible without live Builder
lookups. Reused owner metadata export, the existing saved-cut projection, exact
media declarations, prepared-source admission and native offline renderer. Shared
the API’s saved-cut lookup with the packaging CLI instead of a parallel authoring
store. The packet preserves attribution and exact revisions, and adds copied-byte
commitments without pretending source declarations previously committed bytes.

Outcome: a new-directory local CLI packages the actual saved pilot, one exact
Journey and both real clips. A bundled native consumer rendered the packet from
an isolated static server with no API routes and connect-src none. Scene and tunnel
hashes repeat across reverse seeks and an inactive gap; one native renderer and
the feature cache release afterward.27 affected checks, syntax checks, production
build and browser bundle pass. Temporary server exit0 and all process baselines
restored. No authoring mutation or extra audio clock is introduced.

Corrections preserved: the first API import edit placed an import before the
executable header; syntax checking caught it before launch and the header was
restored. The first static browser proof omitted UTF-8, so Unicode package text
changed during script decoding and the content check correctly refused playback.
The fixture gained explicit UTF-8 and passed. These were bounded development
failures, not owner-data failures or a reason to weaken digest validation.

Reusable Lesson Card candidate: package integrity spans text transport as well
as file copying. Preserve exact UTF-8 metadata and compare both declared content
and actual packaged asset bytes before qualifying rendering. Metadata equality
alone is not evidence of final encoded composition or upstream source authenticity.
