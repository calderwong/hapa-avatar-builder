## What changed

The existing Builder owner creates a separate Tunnel or Location preset from an exact parent Thing revision. Only presentation and validated defaults may change. Renderer, source module, control definitions, credits, rights and capabilities remain admitted through the local registry. New presets begin catalogued and require their own visual qualification. Metadata cannot introduce rendering code.

Preset identities have independent notes and root custody. Parent notes and authorship are not copied. Native revisions use immutable semantic digests, parent links, compare-and-swap heads and actor-scoped idempotency receipts. Explicit retry after an uncertain response reuses the request identity. Root custody stays unchanged through later authoring revisions; publication intents remain local/pending. No database migration, separate storage owner, Overwind acknowledgement, mint or canon is implied.

The existing Library and instance editor now offer Save as new preset, numeric default controls, separate Card identity, parent/source inspection and notes. Library also supports preset revisions. The shared registry loads bounded pages and retains historical references independently from visible latest heads. Saved recipes fetch exact pinned revisions and parent chains before use. Use latest preset revision edits only the draft and supports Undo.

Runtime now applies Thing defaults before instance overrides. Previously it applied only instance overrides, which would have ignored a reusable preset's defaults. Resetting an instance returns to its pinned defaults. Playback remains a single continuous neutral study; measured signals and mixed routes are unqualified.
