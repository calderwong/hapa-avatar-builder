## Interfaces

Protected GET /api/echos/living-light/capabilities, /export?kind=thing|journey&id=ID&revision=REV&includeNotes=true|false, /imports?entityId=ID and /imports/:digest share the existing owner. POST /import/preview takes package; POST /import/commit takes package, previewDigest and idempotencyKey. GET /readiness?songId=ID projects existing selected-source evidence and reports source/signal/route qualification as unresolved. These reads and previews never start analysis, prepare audio or create authoring storage. Body limit is 1 MiB; package budget reserves transport overhead; oversized or incomplete histories fail rather than silently truncate.

The separate cli/living-light.mjs is an API client, never a direct store writer. Its help documents list/get/history/validate/save/fork/notes/note-save/note-revise/note-retract/readiness/export/import/imports/import-record/archive/restore. It uses the existing admin credential through HAPA_AVATAR_ADMIN_TOKEN in the environment and HAPA_AVATAR_API_URL for a literal loopback HTTP authority. It forbids credential argv, unsafe authorities and redirects, bounds input/response/time and emits machine-readable success or typed nonzero failure. Journey save and fork/import previews are read-only dry runs; unqualified dry runs fail before dispatch. Ambiguous mutations are not automatically retried; retain the exact key and reconcile.
