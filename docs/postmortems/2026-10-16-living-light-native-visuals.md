## Evidence and reuse decision

A native catalog fixture painted all 50 definitions outside the source song's
itinerary, with deterministic route evaluation and clean disposal. Inspection
of the contact sheet contradicted that apparent success: many different named
Locations shared the same generic gyro/platform geometry. The host installed
only Passage, Geometry Dance and Journey; the original app installs a much
larger stack. Correct metadata and nonblank pixels were inadequate evidence.

The host now installs the original synchronous visual hooks in source order:
Flow, Passage, Horizon, Realm/Contour, Octave corridors, Water, Fire, Wind,
Dynamics, Electric/Lumen, Geometry Dance, Element, Stage and Journey. These
remain in the one leased WebGL context, under the existing host clock. The
native vendor modules, their hashes, source IDs and attribution are unchanged.
Painted media still wraps the final native scene draw in the shared depth pass.

The figure loader remains unqualified. Its synchronous Octave corridor module
and shared focus shader are installed directly, with tunnel figures disabled.
Celestial Reliquary now refuses with a specific explanation before GPU
acquisition; it no longer silently substitutes fallback geometry. Its catalog
identity and saved recipes remain intact. Figure/texture loading is continuing
goal work, not a permission question or an accepted omission.

The first corrected catalog pass exposed two further integration dependencies:
Alchemical Court's UMD kernel assigned through a local `root` rather than
`window`, leaving its name unbound inside the generated private namespace;
three Realm Locations required the figure module's shared focus shader. The
wrapper now binds that exact UMD export locally, and the host creates the
existing focus program without loading figure textures. No browser-global
export, substitute simulation, vendor rewrite or extra audio owner was added.
