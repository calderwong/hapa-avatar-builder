## Usable behavior

The existing Library now includes All Cards / Tunnels / Locations / Journeys, text search, readiness and tag filters. Search includes descriptions, source attribution, tags, exact Thing IDs and recipe Song IDs. It filters explicitly loaded metadata; More saved presets and More Journey Cards load further owner pages. Six continuous profiles, 21 passage styles and 23 destination IDs retain their separate identities, including the Halo Vault alias. Readiness is derived conservatively: saved authoring never becomes qualified playback merely by appearing as a Card.

Journey Cards show title, mode, use count, duration, notes and author attribution. Inspect reads the exact saved revision and exposes source-time order, source/identity/custody details, portable export and the existing durable recipe notes. Inspection changes neither the editor draft nor audio or preview. Open saved recipe explicitly invokes the existing editor's exact-revision loader; dirty drafts retain the comparison step. An inspector for a recipe from another song remains readable, with opening disabled until that song is selected in Echo. It does not silently switch audio or fork timing.

Thing Cards now show source attribution and linked used-in recipes. These references retain both Journey ID and exact revision; no title join occurs. Saving a recipe refreshes its Library page and Thing use projections. Recipe/cue notes saved in the editor refresh the Journey count; notes saved in the Library use the same native note owner and refresh the Cards. In the Workspace, the unified Library replaces the editor's duplicate saved-Card listing; standalone editor consumers keep their prior listing by default.

Journey reads use the existing protected `/journeys?songId=…&limit=50&offset=…` and exact revision route. Each request has a 30-second deadline; refresh/song change/unmount abort earlier reads and invalidate their response epoch. Pages deduplicate by exact Journey ID. Loading and failure are visible, and a failed metadata read preserves the source Thing browser. No preparation job, renderer, AudioContext, publication, approval or Card birth is triggered by this browsing path.
