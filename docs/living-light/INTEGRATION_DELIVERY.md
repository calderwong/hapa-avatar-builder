## Operator workflow and recovery

1. In Echo Album choose a song, then **Direction script version → Living Light
   → Album Pass**. Open Preview; Play Show auditions it, and Record + Play uses
   the existing live recording workflow. This delivery check made no new recording.
2. Use Video orientation for Landscape or Vertical and expand Preview to inspect
   the complete frame. Hold motion is available. Saving creates a new cut and
   retains the source; merely switching profile does not rewrite it.
3. Open Living Light to study/edit a saved recipe. Select a use to swap its media,
   surface or compatible Location/Tunnel. Locks protect uses and connections.
   A whole-recipe replacement is also undoable, including its save identity.
4. Use Follow Director for the song clock, or Explore for a separate paused-song
   trip. Travel, Back, Home and direct jump reach the existing album/media/Card
   targets. Return restores the original cut, time, selection and draft. Shared
   Hand inspection retains exact historical revisions.

If a source is missing or changed, restore the exact source or explicitly choose
a replacement; there is no title-based substitution. If a saved destination is
older than the catalog head, the exact-cut lookup retains that historical cut.
If preparation fails, use the visible retry after the missing input is resolved.
Unverified stem alignment remains labeled; a neutral study does not manufacture
measured response. Save conflicts retain history and the recoverable draft.
Undo is bounded to the current editing session and is not promised across reload.

Final export still uses its independent saved-cut readiness, exact source and
release gates. A failed candidate stays failed; use the owner's existing rebuild
or retry path for the stated failure. Existing successful exports and the restored
25-second mixed excerpt are retained. Renderer improvement is not a prerequisite
for continuing the album's live-recording workflow. No new full-song render is
required for this delivery audit.

For stale local delivery, first inspect owner health and active work. Use the
existing supervised launcher/reload only when idle; never start a duplicate
server or interrupt an active render. The current strict source/build/API check
and reopened native preview pass. Missing references, human review and broader
graphics qualification are not repaired by simply restarting.
