# Echo Atlas Director — full-library editorial benchmark

The v5 benchmark combines the broader Human Enricher and Quick Sort library, source-bound song interpretations, existing Audio Atlas results, and shared album usage accounting. The immutable media plan and both Director plans exist. This remains a benchmark prototype: technical preparation, saved cuts, creative fit, playback, final rendering and human acceptance are separate outcomes. This draft preserves the preparation checkpoint and adds the subsequent technical pilot result; the dated owner-save, independent API-readback and agent creative-disposition milestones are added below.

Calder's spot check found the same footage repeated across songs. The original pass incorrectly treated optional numeric quality grades as the available human-reviewed library, reducing its selection to 23 clips. The initial source audit found 204 optional detailed Human Enricher records, including 88 Strong/Hero overrides (79 Strong and 9 Hero). Thus 88 was a subset of optional quality overlays, not the count of manual reviews. The dated live owner projection joined 2,894 seen entries (2,684 accepted and 210 rejected); these are catalog entries, not deduplicated physical clips. The historical narrow-pool Quality pass saved 44 cuts across 22 songs. Those receipts remain intact, but the cuts are superseded as album benchmark recommendations.

The later v3 and v4 pilots expanded the library and passed technical checks, yet still produced poor contextual choices. Both remain held unsaved for creative fit. For example, v4 paired a screaming figure with tender Boba Tea Strum lyrics and a cat screenshot with Dear Papa’s wife-following-the-light passage. Passing compilation and increasing clip diversity did not establish an effective music video.

The correction follows the existing Human Enricher and Quick Sort owners. Explicit manual Accept decisions, including retained legacy decisions, establish human acceptance. Human quality overrides and agent grades retain separate attribution. A missing optional numeric grade, description, palette or preferred resolution does not cancel a manual acceptance. Current rejections and negative human overrides can veto selected media.

The frozen catalog contains 3,637 distinct, byte-qualified candidates: 2,310 human-accepted general clips and 1,327 same-song Reference loops. These are dated snapshot counts, not the size of the live library or all historical manual records. Generated Reference lineage does not become human approval. Every song can draw from all 2,310 general candidates plus its own eligible References; the intermediate 192-clip per-song admission cap is removed. Quality and diversity influence selection within this library. Shared usage accounting limits repeated physical footage across cuts and songs without redefining manual acceptance.

The v5 editorial layer contains 192 source-bound briefs: **175 full-lyric interpretations and 17 limited-context interpretations**. Full-lyric briefs describe each song's narrative arc and distinct sections, with exact inherited lyric anchors, positive visual concepts and specific mismatches to avoid. Limited-context briefs explicitly retain their source limitation and do not invent a complete narrative. Every brief records its author, method and source-context hash. Matching these concepts against attributed candidate descriptions is an editorial aid; it does not prove an action is visible in a clip. Agent interpretation, existing visual metadata, actual visual review and human approval remain distinct evidence.

Selection still preserves exact original/runtime media bytes, native source identity, selected current acceptance records, veto aliases and same-song Reference image/loop provenance. Unrelated new review records do not invalidate an unchanged selected record. Selected sources are revalidated during preparation, verification and append. New cuts retain unreviewed status. Atlas source clocks, alignment limits, optional-analysis gaps and owner compiler/playback checks remain explicit; master-only analysis does not imply registered stems exist.

The Atlas continuation preserves the stopped original cohort. Its 25 core-qualified results remain available for revalidation; its 167 unfinished eligible entries remain historical planned entries. The successor contains those same 167 songs with matching sources and requested profiles, fresh attempts and no imported completed states. The coverage report counts each song once by verified lineage. At the checkpoint, 33 of 192 input-eligible songs had core coverage (25 original plus 8 successor), with 8 additional songs excluded for source problems. This is a dated result count, not a claim that the ongoing analysis is complete.

Completed Atlas results can be revalidated for Director use without taking the analysis writer lock, altering the cohort or starting inference. The retained v5 plan uses explicitly selected saved results. The remaining v5 plan can use the bounded existing-analysis follower: it observes that exact cohort, admits only terminal core-qualified results with unchanged source and artifact identity, and prepares one ready song at a time. Its bounds are 30-second polling, at most 12 hours, no new Atlas analysis and no automatic retries. Source stops, identity drift, incomplete prior Director attempts and deadline expiry remain explicit stop conditions.

The follower's default is preparation without append. Explicit apply mode can save qualified Director cuts through the existing owner route; “read-only follower” describes observing/reusing Atlas, not a promise that apply mode makes no owner writes. The ordinary remaining-plan analysis policy is broader than follower mode, so callers must select the follower mode deliberately. Its recorded `follow-status.json` supplies counts, timestamps and gaps, but a recorded waiting/running state alone is not proof of a live process. This draft does not start a follower or install an automation.
