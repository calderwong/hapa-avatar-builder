## What is not established

These are inspected, pinned, named source copies, not asserted byte-identical versions of CJ's eight editor.isf.video links. The editor returned a JavaScript shell in this environment, and exact editor-ID-to-source/revision correspondence remains unverified. The earlier 0.8.3 names assigned to those eight IDs remain withdrawn. This release does not reuse that fictional mapping.

No arbitrary ISF importer, recovered lens, lyric/phoneme/emotion inference, complete light transport, self-collision solution, production Hapa patch or Three.js conversion is claimed.
